# Profile icons

Section and list icons for the profile README, so it does not lean on emoji.

Source: [Phosphor Icons](https://phosphoricons.com) (`duotone` weight), MIT licensed.
Each file is the upstream SVG with `currentColor` replaced by a fixed hex, so the icon
renders the same in GitHub's light and dark themes.

| Colour | Hex | Used for |
|---|---|---|
| Cyan | `#36BCF7` | product, platform, infrastructure |
| Violet | `#8957E5` | craft, frontend, tooling |
| Green | `#2EA043` | testing, quality, measurement |
| Coral | `#D97757` | people, AI, communication |
| Grey | `#6E7681` | muted notes |
